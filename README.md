# Dare Shola Suddenly — portfolio

A single static page: media manager intro, @codeandgameguy results, the Nature Stone Construction landing page, and how partnerships and leads are tracked.

No build step. `index.html` is the site.

## Vercel

1. Push this folder to a Git repository.
2. In Vercel, import the repository.
3. Leave the framework preset as Other. The output directory is the repository root.
4. Deploy. Vercel serves `index.html` as the homepage.

## GitHub Pages

1. Push this folder to a GitHub repository.
2. Open Settings → Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select the branch and set the folder to `/ (root)`.
5. Save. The page is published at the Pages URL GitHub shows.

Paths are relative, so the page also works as a project site (`username.github.io/repo`).
